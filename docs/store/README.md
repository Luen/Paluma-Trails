The icon and feature graphic are rendered from sources in `app/assets/icon/`:

- `icon.svg` → `icon-512.png`
- `feature_graphic.svg` (generated by `tools/brand/build_brand.py`) →
  `feature-graphic.png`

`tools/brand/render_png.sh` renders both.

The screenshots come from the release web build at 540×873 CSS pixels (2×
device pixel ratio) in light mode, with a simulated GPS fix at
`(-18.942978, 146.188905)`, ±8 m: the junction distances are real content, not
a mock. Any headless Chrome driver that can set the geolocation works; the
current set was taken with puppeteer-core.

## Listing copy

| Field | Text |
| --- | --- |
| App name | Paluma Trails |
| Short description (80) | Every track and junction, offline. Trail map for Paluma Range National Park. |
| Full description, first line | Paluma Trails is an offline trail map for Paluma Range National Park, Queensland: every mapped track and numbered junction, with estimated walking times, working without mobile reception. |

Keep “estimated” in any copy about walking times, and do not describe the
content as official or verified. See #52 for the listing itself.
