## Working agreements

- `content/data/**` is the source of truth. `app/assets/bundle/content/**` is
  generated by `tools/paluma_cli` and checked by CI.
- Anything a hiker reads on the trail must work with the network off. If a feature
  cannot, it must be labelled clearly (for example the weather card's "fetched at").
- Estimated walking times are always labelled as estimates, in the UI and in the
  content itself.
